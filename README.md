# College Marketplace

A AI Powered full-stack web application designed for college students to buy and sell items within their campus community.

## Structure
- `frontend/`: Contains the React/Vite web application.
- `backend/`: Contains the Node.js/Express server and API.

## Setup
Refer to individual README files within `frontend/` and `backend/` (if any), or run `npm install` inside both directories to install dependencies.
